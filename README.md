# hj_automouse
Windows 전용 시스템 트레이 기반 마우스 오토클릭 프로그램.

## 주요 기능

### 전역 단축키 제어

시작 (Alt + C + P): 현재 마우스 포인터 위치 기준 지속적 자동 클릭 실행  

정지 (Alt + C + S): 자동 클릭 동작 중단  

### 시스템 트레이

작업표시줄 백그라운드 실행  

우클릭 메뉴 제공 (설정, 종료)  

설정창 (GUI)  

클릭 주기(시간 간격) 사용자 설정 기능  

## 기술 스택

MFC, C++

주요 라이브러리: 시스템 전역 훅, 시스템 트레이, GUI 툴킷

### 사용 방법

프로그램 실행 (트레이 아이콘 등록)

Alt + C + P 입력으로 오토클릭 시작

Alt + C + S 입력으로 오토클릭 정지

트레이 아이콘 우클릭을 통한 설정 변경 및 프로그램 종료
