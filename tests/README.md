# 핵심 로직 테스트

Linux에서 C++17 지원 g++와 pthread로 실행합니다. 테스트 실행 파일은 임시 폴더에 만들고 자동으로 삭제합니다.

```sh
bash tests/run_portable.sh
```

- `chord_tests.cpp`: 눌림·해제 순서, 키 반복, 정지 우선, 추가 modifier 제외, 키 입력 전달/차단 상태
- `interval_tests.cpp`: 간격 범위, 초 소수 변환, 단위 왕복, 오버플로·잘못된 입력
- `engine_tests.cpp`: 실제 `ClickEngine.cpp`를 모의 Win32 API와 연결합니다. 위치 고정 OFF에서는 포인터를 옮기면 다음 클릭이 새 위치에서 발생하고, 좌표 캡처나 포인터 이동 입력을 보내지 않는지 확인합니다. 음수 좌표와 화면 원점을 가로지르는 이동도 포함합니다. 위치 고정 ON에서는 시작 좌표를 한 번만 캡처하고, 이후 포인터를 옮겨도 원래 좌표를 클릭하는지 확인합니다.

두 모드 모두 긴 대기 중 즉시 정지, 정지 후 입력 없음, 시작 키 해제 대기, modifier·물리 버튼 보호, 부분 입력 실패 시 버튼 해제와 오류 통지를 검사합니다. 고정 모드의 가상 데스크톱 좌표 변환·모니터 오류와, 기본 모드가 좌표 캡처·모니터 정보에 의존하지 않는지도 검사합니다. 클릭 위치 검사는 잠금과 조건 변수로 관측된 클릭을 기다립니다.

버전 관리 CLI는 Python 표준 라이브러리로 별도 검증합니다.

```sh
python3 -m unittest discover -s tests -p version_tests.py
```

`win32_stub/`은 테스트에서만 사용합니다. 앱 프로젝트에는 포함하지 않습니다. 모의 API 테스트는 Windows ABI, 실제 키보드 훅, 시스템 트레이, UIPI 또는 실제 클릭 전달을 검증하지 않습니다. Windows에서는 프로젝트 루트 README의 수동 검증 절차를 수행해야 합니다.
